# 💻 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/abhijitpavse/python_programs.git
```

### 2. Navigate to the repository

```bash
cd python_programs
```

### 3. Check Python installation

```bash
python --version
```

### 4. Run a Python program

```bash
python filename.py
```

For Jupyter Notebook work:

```bash
jupyter notebook
```
